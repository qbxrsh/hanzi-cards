# Карточки 汉字

Приложение для изучения китайских иероглифов по карточкам, как в Quizlet. На карточке есть иероглиф, пиньинь, перевод на русский и анимация, показывающая, как его писать.

Работает в браузере, а на iPhone ставится на экран «Домой» и открывается как обычное приложение.

## Возможности

- **Создание карточек с поиском.** Пишешь пиньинь (`xue`, `nihao`), иероглиф или английское слово и выбираешь вариант из списка. В словаре около 11 000 слов HSK 1–9.
- **Автозаполнение.** Пиньинь с тонами и перевод на русский подставляются сами. Под переводом есть кнопки с другими значениями слова. Всё можно отредактировать.
- **Добавление списком.** Можно вставить сразу много слов: по одному в строке, через пробел или запятую. Пиньинь и перевод подтянутся для всех слов, перед добавлением их можно поправить. Свой перевод можно указать сразу: `学习 - учиться`. Слова, которые уже есть в наборе, отмечаются, а слова можно разбить на отдельные иероглифы.
- **Загрузка из файла `.txt` или `.docx`.** Иероглифы берутся из всего файла: из списков, таблиц Word (например, колонки «иероглиф | пиньинь | перевод») и обычного текста. Предложения сами разбиваются на слова. Текстовые файлы читаются в кодировках UTF-8, UTF-16 и GBK.
- **Порядок черт.** Анимация показывает, как писать каждый иероглиф, ключ выделен цветом.
- **Пропись.** Иероглиф можно нарисовать пальцем: приложение проверяет каждую черту и подсказывает после ошибок.
- **Озвучка** голосом, встроенным в телефон.
- **Учёба.** Карточки переворачиваются нажатием, сначала можно показывать иероглиф или перевод. Есть кнопки «Помню / Не помню».
- **Что учить.** Кнопка «Учить…» предлагает: все карточки, трудные, N случайных, по теме или выбрать вручную.
- **Трудные карточки.** Карточка становится трудной сама, если в последних 5 ответах было 2 или больше «Не помню». Её можно отметить и вручную: в карточке или флажком ⚑ прямо во время учёбы. Трудные выделены в списке и на карточке.
- **Темы.** Один список тем на все наборы. Тему можно выбрать вручную или нажать «✨ определить»: при добавлении списком темы ставятся сами. В наборе есть фильтр по темам.
- **Примеры и объяснение.** В карточке есть реальные предложения с переводом из Tatoeba. Кнопка «✨ Объяснить» показывает часть речи, сочетания, счётное слово, частые путаницы и примеры. Всё сохраняется в карточку.
- **Тексты из своих слов.** Выбираешь карточки и нажимаешь «✨ Составить текст». Получается короткий связный текст, выбранные слова подсвечены. Пиньинь над иероглифами и перевод включаются кнопками. Нажатие на предложение показывает его пиньинь и перевод, есть чтение вслух. Тексты сохраняются в набор.
- **Поиск** по иероглифам, пиньиню без тонов и переводу.
- **Наборы** карточек.
- **Резервная копия:** экспорт и импорт в JSON-файл.
- Тёмная тема и частичная работа без интернета.

## Установка на iPhone

1. Открой сайт в **Safari**.
2. Нажми «Поделиться», потом **«На экран „Домой“»**.
3. Пользуйся приложением с иконки на экране «Домой».

> **Важно.** Карточки хранятся только на самом телефоне.
> - У вкладки Safari и у иконки на экране «Домой» раздельное хранилище, поэтому работай всегда с иконки.
> - Иногда нажимай «Сохранить копию» на главном экране и сохраняй файл в «Файлы».

## Как это устроено

Это статический сайт без сборки: HTML, CSS и JavaScript. Для функций с «✨» нужна маленькая прослойка на Cloudflare Workers (папка `hanzi-ai`, в этот репозиторий не входит). Она хранит ключ DeepSeek как секрет и пересылает запросы, поэтому ключа в коде сайта нет.

| Файл | Что это |
|---|---|
| `index.html` | страница приложения |
| `app.js` | логика: наборы, карточки, учёба, темы, трудные |
| `ai.js` | всё, что ходит в сеть кроме перевода: примеры Tatoeba, объяснения, темы и тексты через прослойку |
| `style.css` | стили |
| `dict.txt` | словарь HSK: слово, пиньинь, уровень, английское значение |
| `sw.js` | service worker для работы без интернета |
| `manifest.webmanifest`, `icon-*.png` | иконка и настройки для установки на телефон |

Данные хранятся в `localStorage` браузера.

### Обновление

Загрузи изменённые файлы в репозиторий: **Add file → Upload files → Commit changes**. GitHub Pages обновит сайт примерно за минуту, карточки на телефоне при этом сохранятся.

Чтобы запустить локально, нужен любой статический сервер:

```bash
python -m http.server 8765
```

## Источники данных и библиотеки

- [Hanzi Writer](https://hanziwriter.org): анимация черт и пропись, лицензия MIT. Данные о чертах взяты из [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) под лицензией Arphic Public License.
- [pinyin-pro](https://github.com/zh-lx/pinyin-pro): пиньинь для слов, которых нет в словаре, лицензия MIT.
- [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary): словарь HSK, лицензия MIT. Английские значения в нём взяты из [CC-CEDICT](https://cc-cedict.org) под лицензией CC BY-SA 4.0.
- Перевод на русский делается через Google Translate (неофициальный доступ). Если он не отвечает, используется запасной сервис [MyMemory](https://mymemory.translated.net).
- [Tatoeba](https://tatoeba.org): примеры предложений с переводами, сделанными людьми, лицензия CC BY 2.0 FR.
- [DeepSeek](https://www.deepseek.com): объяснения слов, темы и тексты, через собственную прослойку на Cloudflare Workers.

Библиотеки загружаются с [jsDelivr](https://www.jsdelivr.com).
