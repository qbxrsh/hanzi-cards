# Карточки 汉字

Приложение для изучения китайских иероглифов по карточкам, как в Quizlet. На карточке есть иероглиф, пиньинь, перевод на русский и анимация, показывающая, как его писать.

Работает в браузере, а на iPhone ставится на экран «Домой» и открывается как обычное приложение.

## Возможности

- **Создание карточек с поиском.** Пишешь пиньинь (`xue`, `nihao`), иероглиф или английское слово и выбираешь вариант из списка. В словаре около 11 000 слов HSK 1–9.
- **Автозаполнение.** Пиньинь с тонами и перевод на русский подставляются сами. Под переводом есть кнопки с другими значениями слова. Всё можно отредактировать.
- **Порядок черт.** Анимация показывает, как писать каждый иероглиф, ключ выделен цветом.
- **Пропись.** Иероглиф можно нарисовать пальцем: приложение проверяет каждую черту и подсказывает после ошибок.
- **Озвучка** голосом, встроенным в телефон.
- **Учёба.** Карточки переворачиваются нажатием, сначала можно показывать иероглиф или перевод. Есть кнопки «Помню / Не помню» и отдельное повторение трудных карточек.
- **Наборы** карточек.
- **Резервная копия:** экспорт и импорт в JSON-файл.
- Тёмная тема и частичная работа без интернета.

## Установка на iPhone

1. Открой сайт в **Safari**.
2. Нажми «Поделиться», потом **«На экран „Домой“»**.
3. Пользуйся приложением с иконки на экране «Домой».

> **Важно.** Карточки хранятся только на самом телефоне.
> - У вкладки Safari и у иконки на экране «Домой» раздельное хранилище, поэтому работай всегда с иконки.
> - Иногда нажимай «Сохранить копию» на главном экране и сохраняй файл в «Файлы».

## Как это устроено

Это статический сайт без сервера и без сборки: HTML, CSS и JavaScript.

| Файл | Что это |
|---|---|
| `index.html` | страница приложения |
| `app.js` | вся логика |
| `style.css` | стили |
| `dict.txt` | словарь HSK: слово, пиньинь, уровень, английское значение |
| `sw.js` | service worker для работы без интернета |
| `manifest.webmanifest`, `icon-*.png` | иконка и настройки для установки на телефон |

Данные хранятся в `localStorage` браузера.

### Обновление

Загрузи изменённые файлы в репозиторий: **Add file → Upload files → Commit changes**. GitHub Pages обновит сайт примерно за минуту, карточки на телефоне при этом сохранятся.

Чтобы запустить локально, нужен любой статический сервер:

```bash
python -m http.server 8765
```

## Источники данных и библиотеки

- [Hanzi Writer](https://hanziwriter.org): анимация черт и пропись, лицензия MIT. Данные о чертах взяты из [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) под лицензией Arphic Public License.
- [pinyin-pro](https://github.com/zh-lx/pinyin-pro): пиньинь для слов, которых нет в словаре, лицензия MIT.
- [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary): словарь HSK, лицензия MIT. Английские значения в нём взяты из [CC-CEDICT](https://cc-cedict.org) под лицензией CC BY-SA 4.0.
- Перевод на русский делается через Google Translate (неофициальный доступ). Если он не отвечает, используется запасной сервис [MyMemory](https://mymemory.translated.net).

Библиотеки загружаются с [jsDelivr](https://www.jsdelivr.com).
